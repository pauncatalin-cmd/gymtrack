# GymTrack Pro

Versiunea include:
- programul tău de 4 zile
- bifare pe fiecare serie
- kg și repetări
- timer pentru pauză
- timp total
- calorii estimate pe baza greutății corporale
- istoric
- PR pentru fiecare exercițiu
- grafic de progres
- imagini pentru aparatele pe care le-ai trimis
- funcționare PWA și offline

## Publicare pe GitHub Pages
1. Creează un repository nou sau înlocuiește fișierele din repository-ul vechi.
2. Urcă toate fișierele din ZIP în rădăcina repository-ului.
3. Settings > Pages.
4. Deploy from a branch.
5. Branch `main`, folder `/root`.
6. Deschide linkul Pages în Safari.
7. Share > Add to Home Screen.

În aplicație, intră la Setări și introdu greutatea corporală pentru calculul estimativ al caloriilor.

Datele sunt salvate local pe dispozitiv în localStorage.
