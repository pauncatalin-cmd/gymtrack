# GymTrack, versiunea în limba română

Am tradus denumirile exercițiilor în română și am eliminat textele germane din imaginile aparatelor prin decuparea capturilor.

Denumiri folosite:
- Împins la piept cu bara
- Presă pentru piept la aparat
- Fluturări la aparat
- Extensii triceps la cablu
- Extensii triceps deasupra capului
- Tracțiuni la helcometru
- Ramat la aparat
- Ramat la cablu
- Fluturări inverse la aparat
- Flexii biceps cu bara EZ
- Flexii ciocan cu gantere
- Presă pentru picioare
- Extensii pentru cvadriceps
- Flexii pentru femurali
- Îndreptări românești
- Ridicări pe vârfuri

Pentru GitHub Pages, înlocuiește fișierele vechi cu cele din acest ZIP și păstrează folderul assets.
