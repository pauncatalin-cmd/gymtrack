# GymTrack, versiunea finală

Funcții incluse:
- program de 4 zile
- antrenamentul zilei
- serii, repetări, kg și RIR
- recomandare automată pentru progresia greutății
- încălzire separată
- timer pentru pauze
- volum total pe antrenament
- volum săptămânal pe grupe musculare
- calendar cu zilele antrenate
- înlocuire rapidă a exercițiilor
- notițe pentru fiecare exercițiu
- record greutate, record repetări și 1RM estimat
- grafic de progres
- ecran final cu rezumat
- calorii estimate
- export și import backup
- funcționare PWA și offline

## Instalare pe GitHub Pages
1. Dezarhivează ZIP-ul.
2. Urcă toate fișierele în rădăcina repository-ului GitHub.
3. Settings > Pages.
4. Deploy from a branch.
5. Selectează branch-ul main și folderul /root.
6. Deschide linkul Pages pe iPhone.
7. Safari > Share > Add to Home Screen.

Datele sunt salvate local pe dispozitiv.


## Imagini exerciții
Imaginile exercițiilor sunt afișate din sursele online McFIT și necesită conexiune la internet pentru încărcare.


## Imagini locale
Versiunea v3 nu mai încarcă imaginile de pe servere externe.
Imaginile sunt incluse direct în aplicație, deci apar și offline.
Cinci imagini sunt bazate pe capturile McFIT furnizate în conversație.
Pentru celelalte exerciții sunt incluse diagrame locale, fără text german.
